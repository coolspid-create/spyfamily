# 가족 X 스케줄러 프로덕션 릴리스 1.1.2

## Play Console 업로드 파일

- 트랙: 프로덕션
- 버전 이름: 1.1.2
- 버전 코드: 13
- AAB 파일: `play-store/aab/family-scheduler-1.1.2-code13.aab`
- SHA-256: `BB39522236E3F35357D469FA7B99A7776FD10E597E5DEDE72F9DC29E36FF84BC`

## 릴리스 노트

가족 X 스케줄러는 아이의 복잡한 하루 일정과 매달 반복되는 주요 지출을 한눈에 정리하기 위한 앱입니다.

이번 업데이트에서는 하단 네비게이션 바가 안정적으로 고정되도록 개선하고, 화면 스크롤이 어색하게 동작하던 문제를 수정했습니다.

또한 기존 사용자는 첫 사용 온보딩 안내가 다시 표시되지 않도록 조정했습니다.

## 반영 내용

- 하단 네비게이션 바 고정 안정화
- 화면 스크롤 동작 개선
- 기존 유저 온보딩 스킵 처리

## 검증

- `npm run build`
- `npx cap sync android`
- `gradlew bundleRelease`

## Play Console 입력 위치

프로덕션 > 새 버전 만들기 > App Bundle 업로드 후, 릴리스 세부정보의 릴리스 노트에 위 문구를 입력합니다.
