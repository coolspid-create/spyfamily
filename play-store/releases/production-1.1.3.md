## 릴리스 노트

가족 X 스케줄러는 아이의 복잡한 하루 일정과 매달 반복되는 주요 지출을 한눈에 정리하기 위한 앱입니다.

이번 업데이트에서는 화면 전환 애니메이션을 더 일관되게 맞추고, 하단 메뉴와 요일 선택 영역의 여백을 개선했습니다.

또한 새 일정과 결제 내역 추가 화면에서 스크롤바로 인해 화면 폭이 흔들리던 문제를 수정하고, 오늘할일 추가 시 첫 항목 애니메이션이 어색하게 보이던 현상을 개선했습니다.

## 반영 내용

- 메인 탭 전환 애니메이션 일관화
- 오늘할일 첫 항목 추가 애니메이션 개선
- 주간일정/결제관리 추가 폼 확장 시 화면 폭 흔들림 방지
- 하단 메뉴 safe-area 여백 개선
- 요일 선택 바 상하 여백 조정
- 개인정보처리방침 및 데이터 삭제 안내 링크 상태 확인

## 검증

- `npm run build`
- `npx cap sync android`
- `gradlew bundleRelease`

## Play Console 입력 위치

프로덕션 > 새 버전 만들기 > App Bundle 업로드 후, 릴리스 세부정보의 릴리스 노트에 위 문구를 입력합니다.
