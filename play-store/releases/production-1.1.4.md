## 릴리스 노트

이번 업데이트에서는 월간일정과 결제관리 화면의 레이아웃 안정성을 개선했습니다.

긴 결제 항목명이 월간일정 카드 바깥으로 밀려나지 않도록 정리하고, Android 앱 실행 시 상단에 중복 타이틀/스플래시 배경이 남아 보일 수 있는 네이티브 화면 여백 설정을 수정했습니다.

또한 주요 화면의 장식 요소가 화면 폭 밖으로 잡히지 않도록 정리하고, 코드 정적 검사를 통과하도록 보조 스크립트와 MVP 컴포넌트의 React 규칙 위반을 개선했습니다.

월간일정, 결제관리, 가족일정의 접힘/수정 폼 애니메이션도 메인 탭 전환과 같은 짧고 일관된 전환 효과로 통일했습니다.

## 반영 내용

- 월간일정 결제관리/가족일정 카드 overflow 방지
- Android 네이티브 상단 여백에서 스플래시 배경이 보이던 문제 제거
- 오늘할일/결제관리/가족일정 장식 요소 가로 넘침 방지
- MVP 컴포넌트 React lint 오류 수정
- PDF/썸네일 생성 보조 스크립트 lint 오류 수정
- 개인정보처리방침 및 데이터 삭제 안내 페이지 상태 재확인
- 월간일정/결제관리/가족일정 메뉴 애니메이션 일관화

## 검증

- `npm run lint`
- `npm run build`
- `npx cap sync android`
- `gradlew bundleRelease`

## Play Console 입력 위치

프로덕션 > 새 버전 만들기 > App Bundle 업로드 후, 릴리스 세부정보의 릴리스 노트에 위 문구를 입력합니다.
