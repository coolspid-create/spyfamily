## 릴리스 노트

가족 X 스케줄러는 아이의 복잡한 하루 일정과 매달 반복되는 주요 지출을 한눈에 정리하기 위한 앱입니다.

이번 업데이트에서는 처음 앱을 여는 사용자가 주간일정, 오늘할일, 월간일정, 결제관리, 가족일정의 역할을 빠르게 이해할 수 있도록 첫 사용 가이드를 추가했습니다.

또한 화면 간 이동이 더 부드럽도록 탭 전환 애니메이션과 레이아웃을 다듬고, 월간일정과 결제관리 화면의 스크롤 안정성을 개선했습니다.

## 반영 내용

- 첫 사용 가이드 추가
- 주요 메뉴별 원형 포커스 안내 적용
- 안내 대상 선택 시 다음 단계로 자동 이동
- 상단 닫기 버튼으로 가이드 종료
- 전체 화면 밀도와 간격 일부 압축
- 월간일정/결제관리 탭 전환 애니메이션 최적화
- 하단 메뉴 고정 및 가로 스크롤 방지 안정화
- 아이 일상 기록 MVP 화면은 이번 업로드 빌드에서 제외

## 검증

- `npm run lint`
- `npm run build`
- `npx cap sync android`
- `gradlew bundleRelease`

## Play Console 입력 위치

프로덕션 > 새 버전 만들기 > App Bundle 업로드 후, 릴리스 세부정보의 릴리스 노트에 위 문구를 입력합니다.
