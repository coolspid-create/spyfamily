## 릴리스 노트

이번 업데이트에서는 메인 앱의 화면 전환과 하단 네비게이션 UI 안정성을 개선했습니다.

하단 메뉴를 더 밝고 읽기 쉬운 스타일로 정리하고, 앱 프레임의 좌우 라인과 하단바가 어긋나 보이지 않도록 맞췄습니다. 상단 헤더와 오른쪽 테두리가 만나는 지점에 얇은 밝은 선이 보일 수 있던 부분도 정리했습니다.

온보딩 가이드의 마지막 안내 화면에서는 시작하기 버튼이 문구 아래에 자연스럽게 배치되도록 조정했습니다.

## 반영 내용

- 메인 하단 네비게이션 색상 및 활성/비활성 메뉴 대비 개선
- 하단 네비게이션과 앱 프레임 좌우 라인 정렬 개선
- 상단 헤더와 오른쪽 프레임 라인 접점의 미세한 밝은 선 제거
- 온보딩 마지막 화면의 시작하기 버튼 위치 및 크기 조정
- 메인 탭 전환 지연 구조 개선
- 메인 앱과 MVP 다이어리 개발 서버/진입 경로 분리

## 검증

- `npm run lint`
- `npm run build`
- `npx cap sync android`
- `gradlew bundleRelease`

## Play Console 입력 위치

프로덕션 > 새 버전 만들기 > App Bundle 업로드 후, 릴리스 세부정보의 릴리스 노트에 위 문구를 입력합니다.
